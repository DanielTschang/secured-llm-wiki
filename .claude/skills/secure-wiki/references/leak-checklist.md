# 洩漏檢查清單

合併前逐項檢查。每一項都以「只有 `sp_cd` 權限的使用者，能否因此得知 `sp_opc` 的任何資訊」為判斷標準。

## 標籤與權限
- [ ] 所有新產物都有標籤，且由程式從輸入計算（聯集），沒有任何地方讓 LLM 產生或修改標籤。
- [ ] 沒有用主題、內容或檔名推論標籤。
- [ ] `can_read` 只使用平台回傳的可讀 space；沒有任何權限資料被寫入本系統。
- [ ] 平台不可用時 fail closed。
- [ ] 請求中的身分或權限參數被忽略。

## Ingest 邊界
- [ ] ingest 的 LLM 輸入只來自單一 space 與標準術語表，且有執行期檢查。
- [ ] 寫入前驗證產物標籤恰為 `{space_id}`；違反時中止並告警。
- [ ] 沒有寫入標準術語表或其他 space。
- [ ] include 未被展開，跨 space 連結未被跟隨。
- [ ] 統計（IDF、去重、計數、排序）只在單一 space 內計算。
- [ ] 寫入帶版本，過期寫入會被拒絕。

## View 與查詢
- [ ] 檢索與圖遍歷先過濾再計算。
- [ ] 快取 key 包含 effective labels 與世代號碼。
- [ ] view 與回答沒有被回寫、沒有被當作輸入。
- [ ] 輸出前重新驗證引用來源的可讀性。
- [ ] 模型工具的權限參數由程式注入，模型無法修改。

## 存在性與側通道
- [ ] 無權限與查無資料的回應內容、狀態碼一致。
- [ ] 沒有顯示被過濾的筆數、總數或分頁資訊。
- [ ] 錯誤訊息不含標題、概念名稱、space 名稱。
- [ ] 權限判斷在任何只有「存在時」才會執行的昂貴操作之前。
- [ ] 全域列表（最近更新、熱門、自動完成、推薦）只基於讀者可讀的內容。

## 可觀測性與基礎設施
- [ ] log、trace、例外、metrics、metric label 只含 ID 與數值。
- [ ] 佇列訊息只含 ID。
- [ ] 圖片只經驗權端點提供。
- [ ] 新元件的 NetworkPolicy 預設拒絕；ServiceAccount 只擁有必要 space 的權限。
- [ ] 沒有把金鑰放進 k8s Secret 或程式碼。

## 測試
- [ ] 新行為有對應的 leak 測試（使用合成測試集的 canary 與四種模擬使用者）。
- [ ] `make leak` 通過。
- [ ] 若涉及 `deploy/`，基礎設施隔離測試通過。
